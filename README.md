# Dashboard Application

A feature-rich and responsive dashboard application built using React. This project includes dynamic theming, interactive components, and real-time updates, providing a comprehensive overview of key metrics and functionalities.

## Features

- **Dynamic Theming**: Light and dark mode toggling with smooth transitions.
- **Responsive Design**: Optimized for all screen sizes, ensuring usability across devices.
- **Search Bar**: Quick access to search functionalities (hidden on small screens).
- **Typewriter Effect**: Animated text using `react-simple-typewriter` for a dynamic visual experience.
- **Interactive Components**: Includes navigation menus, notifications, and user profile options.

## Technologies Used

- **React**: For building the user interface.
- **Tailwind CSS**: For responsive and utility-first styling.
- **React Simple Typewriter**: For creating typewriter animations.
- **MUI Icons**: For modern and accessible iconography.

## Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/MDAEJA/Dashboars_EV.git
   ```

2. Navigate to the project directory:
   ```bash
   cd dashboard
   ```

3. Install dependencies:
   ```bash
   npm install
   ```

4. Start the development server:
   ```bash
   npm start
   ```

## Usage

- Navigate through the sidebar to access different sections of the dashboard.
- Toggle between light and dark modes using the theme switcher.
- Interact with notifications, search, and user profile options from the header.
- Experience animated text headers using the typewriter effect.
